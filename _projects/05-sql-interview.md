    - Married publicly available SQL practice questions with a GPT LLM to give users instant, personalized feedback on SQL so users don't have to pay for additional services or worry about setting up their own SQL database. 
    - Used few-shot prompting and OpenAI SDK.  
    - Built web-app with Streamlit and OOP to provide simple and seamless user experience.
